# keyuli.space

Personal homepage of Keyu Li (李克钰), served by GitHub Pages at <https://weizhihao1.github.io> (keyuli.space).

## Updating

- **Content** (bio, news, publications, experience, education, links): edit `_data/home.yml`. HTML is allowed in text fields.
- **Resume**: overwrite `files/Keyu_Li_CV_EN.pdf` and `files/Keyu_Li_CV_ZH.pdf` (keep the file names so the links stay stable).
- **Layout / styles**: `_layouts/home.html` (single self-contained page).

The site still builds with the Academic Pages Jekyll theme (MIT, see `LICENSE`), which only renders the 404 page now.
Older versions are kept in the `v1-academicpages` tag and the `backup/academicpages-2026-10-28` branch.
